# 工作区占用台账

本文件登记**当前被某个 worktree / 分支占用中的目录与子系统**。同一个仓库可以同时存在多个 `git worktree`，它们互不共享文件，但共享同一个远端，因此需要避免「两个工作区同时改同一批文件」。

## 登记规则

1. **开工前**：读下面的「当前占用」表，确认你要动的目录没有冲突。
2. **动手前**：加一行，写清 worktree 名、分支、占用的目录、开始时间、范围。
3. **收工后**：删掉自己的行；跨多天的长期工作改成「进行中」并更新说明。
4. **不要删除别人的行** —— 只维护自己登记的条目。发现别人那行明显过期（worktree 已不存在），在备注里写「疑似过期」，不要直接删。
