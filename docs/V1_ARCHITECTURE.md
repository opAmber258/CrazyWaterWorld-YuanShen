## 2. 架构决策

### 2.1 副本制与本轮交付边界（用户确认后纠偏）

v1 目标仍是每轮独立任务海域。先前将其替换成「连续世界 + 惰性区块卸载」未经用户同意，现撤回该架构替代；区块卸载不等于副本生成。

本轮只实现地图 → 相邻航线/共享任务勾选 → 下潜 → 全部在线玩家安全登船。**任务海域实例地形已接入首个版本**（2026-11-06）：每轮在深海维度远处保留带 `x = 20000 + n*1024, y = -84, z = 0` 生成一片半径约 96 格、高约 70 格的封闭洞穴，物理船整船传送到锚点后全员登船。地形纯坐标确定性生成，不写区块差异；跨维度船迁移仍未做（同维度远距离保留带）。任务目标、沉船 POI、生物和报酬结算尚未接入。节点锚点仅兼容旧数据/诊断，不是物理靠泊点。

完整海图尺寸按安装版 1.13.5.0 XML 的 8000×800；M1 只显示寒冷深穴的手工 1200×800 裁剪区域，等比例绘制。五节点布局是适配而非原作随机图复刻。

### 2.2 战役状态

- `campaign/CampaignState extends SavedData`，固定挂在 `the_deep` 维度。
- 字段：`currentNode`、`credits`（共享钱包）、`visited`、`roundsCompleted`、
  `RoundState`、`snapshot`（出发前快照）。
- `RoundState`：`AT_NODE / DIVING / FAILED`，记录 `origin / destination / startedAt`。
- `campaign/CampaignMap`：5 个节点，边双向；节点 0 起始哨站、1 B 中继站（分叉）、
  2/3 两条航路、4 深层哨站（汇合）。

### 2.3 巡回生命周期

1. `AT_NODE`：在节点上；`/barotrauma campaign travel <node>` 校验相邻边。
2. 出发：拍快照 → `DIVING`，记录起点/终点/时间。
3. 玩家接近节点自动抵达已禁用。现阶段仅管理员 `arrive` 明确调试推进；它不代表物理靠泊。
4. 抵达：`currentNode = destination`、`roundsCompleted++`、`saveEverything` 自动存档。
5. 失败：`DIVING` 且存在快照 → `FAILED` → 读快照（节点/资金/轮次恢复）。
6. 读档：`DIVING` 状态可以继续（不强制失败）；目的地丢失则回到 `AT_NODE`。

M1 只恢复战役数据；玩家/船的实际位置回档在 M3 接复活小艇时一起做。

### 2.4 复活小艇（M3）

`VsPilot` 只能管理一艘物理船，所以 v1 **不做第二艘 VS2 潜艇**。方案：

- 新增轻量载具实体 `RespawnShuttleEntity`（座位 + 简单推进 + 对接检测），不是完整潜艇；
- 死亡 → 在关卡水域远离主潜艇处生成 → 玩家在艇内复活；
- 限时（默认 120 秒）开回主潜艇并对接；
- 超时/被毁 → 小艇自动返回哨站 → 本轮失败 → 回档。

这是 v1 的简化，需求文档 §5.10 已标注「不是完整小艇模拟」。

### 2.5 任务与经济（M2）

- 任务从「固定 5 条」改成**每轮实例**：出发时沿航线/终点生成 1–3 条；
- 状态机补 `FAILED`；按类型计时（救援/紧急运送有时限）；
- 部分完成 → 部分报酬；失败不阻断抵达推进；
- 共享钱包：用 `CampaignState.credits` 取代 `MissionSavedData` 的按玩家 credits，
  任务终端/商店 UI 跟着改；
- 升级 3 条线：船体/引擎/氧气，各 2–3 级。

### 2.6 电力与氧气（M4）

- 反应堆/发电机 + 电池 + 全船电网（不做布线）；
- `MachineCount` 真正统计反应堆/泵/氧气机，喂给 `ShipSimulation`；
- 氧气机耗电，产出船内氧气；`oxygenPercent` 驱动窒息伤害；
- HUD：氧气条、电力/进水告警、断电提示。

### 2.7 生物与战斗（M5）

- 2 种 `Monster`：船外袭击者（撞船/打船壳）、船内入侵者（近战玩家/设备）；
- 手持近战 + 远程武器与弹药；船内炮塔列为 Should；
- 按轮次/海域生成，数量上限；不做 Boss/武器树。

## 5. 风险与待决

- **任务海域实例是首版**：封闭洞穴 + 整船传送已接，但没有目标/POI/生物/结算；返航与下一轮选址尚未接。
- **实例槽位会无限外扩**：`x = 20000 + n*1024`，单存档数千轮才会接近世界边界，远超 v1 规模。
- **单物理船**：复活小艇只能做轻量载具；多船支持不在 v1。
- **两套 credits**：M1 的共享钱包还没接任务终端，M2 必须统一，否则玩家会看到两个余额。
- **到站集成待实现**：玩家坐标自动抵达已禁用，仅管理员显式调试推进。
- **中途存档**：当前读档可继续 `DIVING`；是否允许中途手动存档/防 SL 大法，M2 再定。
- **性能**：120 FPS 的主要瓶颈仍是水面/粒子；M6 前要留出优化窗口。
